# 🏋️ FITZONE – Gym Management System

FITZONE is a web-based Gym Management System developed using Python and Django. It helps manage gym activities, services, trainers, memberships, and customer inquiries through a simple and user-friendly interface.

## 🚀 Features

- **Home Page:** Modern and responsive gym website interface.
- **About Us:** Information about the gym and its services.
- **Services:** Display of gym services and facilities.
- **Trainer Management:** Manage trainer-related information.
- **Contact Us:** Contact form for customer inquiries.
- **Admin Panel:** Manage application data through Django Admin.
- **Database Management:** Store and manage application data using SQLite.

## 🛠️ Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- SQLite3
- Bootstrap (if used)

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Sakshi123342/FITZONE-gym-management-.git
```

### 2. Open Project Folder

```bash
cd FITZONE-gym-management-
```

### 3. Create Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

**Windows:**
```bash
venv\Scripts\activate
```

### 5. Install Django

```bash
pip install django
```

### 6. Apply Migrations

```bash
python manage.py migrate
```

### 7. Run Development Server

```bash
python manage.py runserver
```

Open in browser:

http://127.0.0.1:8000/
